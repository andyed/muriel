# muriel v0.15.0 — muriel designs behavior, and the jury sees sequences

*Released 2026-10-30.*

muriel started as a visual-production toolkit. This release makes it an
interaction designer as well: it decides which work a flow should ask of a
person, checks that the flow holds together from one state to the next, and
judges the result with a jury that can now see close-up finish and whole
sequences. 172 commits since v0.14.0; the full list is in the
[CHANGELOG](../CHANGELOG.md#0150--2026-10-30).

---

## Headline 1 — design the work before arranging the controls

`SKILL.md` now describes muriel as an interaction and visual-design
collaborator, grounded in cognitive psychology and HCI. Four references carry
that:

- **[`task-analysis.md`](../plugins/muriel/skills/compose/references/task-analysis.md)**
  turns a goal into alternative methods and selection rules (can the person
  see which method applies?), the knowledge each step assumes, a first-use
  cognitive walkthrough, and acceptance journeys. It loads before anyone
  designs or changes a multi-step flow.
- **[`goms.md`](../plugins/muriel/skills/compose/references/goms.md)** says
  which GOMS model answers which question. All four variants estimate time.
  CMN-GOMS and NGOMSL also predict operator sequences, and NGOMSL predicts
  working-memory load and relative learning time. Project Ernestine is the
  worked lesson: a workstation that removed a keystroke per call measured
  0.65 s slower, because the saved steps were off the critical path.
- **[`task-observation.md`](../plugins/muriel/skills/compose/references/task-observation.md)**
  turns interaction events into evidence, after Hilbert and Redmiles, Uzilla,
  and *Instrumenting the Dynamic Web*: activation is not acceptance, ready is
  not delivered, and a log does not reveal intent.
- **[`human-capabilities.md`](../plugins/muriel/skills/compose/references/human-capabilities.md)
  and [`microstrategies.md`](../plugins/muriel/skills/compose/references/microstrategies.md)**
  hold the research grounding: the split of work between people and AI, and
  Gray's *Milliseconds Matter* on how small access costs change the routines
  people adopt.

[`interaction-contracts.md`](../plugins/muriel/skills/compose/references/interaction-contracts.md)
gains a continuity section, because each state can pass while the sequence
fails. The next action stays put. A control that changes meaning cannot
misfire on a tap aimed at its old label. One indicator shows one quantity.
Results carry the revision that produced them. Output is checked where it
lands.

Semantic zoom, linked displays, brushing, zooming interfaces, and faceted
exploration share one contract,
[`multiscale-coordination.md`](../plugins/muriel/skills/compose/references/multiscale-coordination.md):
stable identity across levels, explicit selection and query semantics,
recoverable gestures. Adapters cover D3, Vega-Lite, ECharts, and
Canvas/WebGL, and the [Linked Atlas lab](https://muriel.mindbendingpixels.com/examples/linked-atlas/)
is a working example.

## Headline 2 — seven jurors

v0.14.0 shipped five seats. Two more ship here, each with a lens no other
seat has.

- **The Loupe** judges finish in 4× close-ups cut by `muriel loupe`: line
  ends that land, joints that meet, text that isn't clipped. It never sees
  the whole composition, so it cannot fill in a joint the way a reviewer at
  viewing scale does.
- **The Walker** judges a flow. It gets the task and an ordered filmstrip of
  every settled state, with a manifest of the next action's name, position,
  enabled state, and focus. At each step it asks the four
  cognitive-walkthrough questions, and across the journey it looks for what
  no single frame shows: a moving target, a button that changes meaning under
  the finger, a stage the person must trigger for no reason of their own, a
  journey that ends at "ready". It is denied the design rationale and the
  implementer's claims.

After its walk, the Walker checks
[`flow-patterns.md`](../plugins/muriel/skills/compose/references/flow-patterns.md):
twelve sequence failures, each with a fix, a source (WCAG 2.2, Apple HIG,
Tidwell's *Designing Interfaces*), and a status. Findings are tagged
`source: walk` or `source: pattern`, so the list can be cut if it only
repeats the walk. The chair, never a seat, promotes a pattern from candidate
to confirmed when the ledger records its fix.

The Walker's first sitting was on Protoplasm's video export. The three
problems a user had reported (one bar for playback and job progress, a
manual prepare step, actions that moved) were fixed in that build. The seat
found ten more, five confirmed against code, frames, and delivered files,
including a button that changed from Cancel to Download in place with
nothing to absorb a tap aimed at Cancel.

## Also in this release

- **Diagrams.** Seven generators: `comparison_pair`, `sankey`, `treemap`,
  `dendrogram`, `dag`, `heat_grid`, `spectrum`, plus `cycle(hub=…)` and a
  library of 30 Lucide icons. Diagram SVGs carry an accessible-figure
  contract (`role="img"`, `<title>`, `<desc>`), enforced by
  `muriel diagram-check`, and the core generators carry their data in
  attributes the tests read back. `muriel diagram-export --strict` writes SVG 1.1 colours for
  PowerPoint-class renderers.
- **`muriel line-ends`** fails any stroke that ends on nothing, measured in
  the rendered page. It enters the jury as a finding of fact.
- **Wunderkammer collections.** `muriel.collection` builds and validates the
  one-file collection documents [Wunderkammer](https://github.com/andyed/wunderkammer)
  shows, pinned to its releases; `references/collections.md` is the front
  door.
- **A prose channel**, `channels/prose.md`, says how to write the plain text
  people read: what the first lines must answer, structure and sentence
  rules, registers from store listing to agent report. `channels/readme.md`
  covers repo front pages.
- **Contrast repair.** `muriel contrast --repair FG BG` returns the nearest
  same-hue colour that clears 8:1, scored after 8-bit rounding.
- **Spatial at scale.** A pixel/DOM hybrid tile field takes the `spatial`
  channel past a few hundred items: every item a GPU quad, and DOM cards only
  where focus needs them.
- **The docs build fails on a broken internal link**, and the site now
  features Wunderkammer and its HyperFrames films.

## Fixes

- The provenance stamp now reports the installed version; it had reported
  0.6.0 since that release.
- `muriel import` and `import-corpus` keep `rem`/`em` font sizes,
  `label-caps` families, and letter-spacing from design.md files.
- `TileField` draws at the right gamma, and atlas tiles no longer swap,
  leak, or go missing.
- Cycle diagram arcs start on their source node's outline, and
  `pyramid(proportional=True)` is proportional.
- `muriel line-ends` exits 2 for a missing file, with or without Playwright
  installed.

Details for each are in the [CHANGELOG](../CHANGELOG.md#0150--2026-10-30).

## Upgrading

From a checkout:

```bash
cd ~/Documents/dev/muriel && git pull && ./install.sh
```

The agents mount is one directory symlink, so the Loupe and the Walker appear
without a re-run. The Python package:

```bash
pip install https://github.com/andyed/muriel/releases/download/v0.15.0/muriel-0.15.0-py3-none-any.whl
```

## Known gaps

- **The Walker has sat once.** Whether its pattern pass finds anything the
  walk does not is untested. muriel has no tool for capturing a filmstrip
  yet; the chair drives the flow with the host project's own test harness.
- **Task analysis is not yet compared with a baseline.**
  [`task-analysis-evaluation.md`](../plugins/muriel/skills/compose/references/task-analysis-evaluation.md)
  names the smallest run that would show whether it changes design decisions.
- **The ledger still has no sink.** Pattern promotion depends on it, so for
  now the chair records dispositions by hand.
- **The illustrated jury page is held back** until its visual is finished.
