# muriel

![License: MIT](https://img.shields.io/badge/license-MIT-e6e4d2?labelColor=0a0a0f)
![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-e6e4d2?labelColor=0a0a0f&logo=python&logoColor=white)
![Claude Code plugin](https://img.shields.io/badge/Claude_Code-plugin-e6e4d2?labelColor=0a0a0f)
![Latest release](https://img.shields.io/github/v/release/andyed/muriel?labelColor=0a0a0f&color=e6e4d2&logo=github&logoColor=white)

muriel is a design skill for coding agents. It translates between design languages, from the Visible Language Workshop's typography-as-data to film-style sci-fi interfaces, and expresses them in a multitude of mediums, from paper figures to video. It juries its own work. And it keeps every piece on brand and readable, with tokens from one `brand.toml` and text held to 8:1 contrast.

Artifacts are generated by scripts saved next to them, so they can be rerun when the data changes.

It runs as a Claude Code plugin or in any harness that reads the Agent Skills format. The Python package and `muriel` CLI also work without an agent. The name is Muriel Cooper's; she founded the Visible Language Workshop at MIT.

Examples are in the gallery at [muriel.mindbendingpixels.com](https://muriel.mindbendingpixels.com), a site built with muriel.

## Install

In a Claude Code session:

```text
/plugin marketplace add andyed/muriel
/plugin install muriel@andyed-muriel
```

Invoke it with `/muriel:compose`, or let the agent load it when a task has an open visual decision. The critique agent and jury seats install with it. `/plugin uninstall` removes everything.

For other harnesses, the Python package, or a development checkout, see [More ways to install](#more-ways-to-install).

## Channels

A channel is one output medium. Each has a markdown file of recipes, tools, and anti-patterns under [`channels/`](plugins/muriel/skills/compose/channels/), and the agent reads the one that matches the job.

| Channel | For (main tools) |
|---|---|
| [Raster](plugins/muriel/skills/compose/channels/raster.md) | Store assets, icons, banners, wordmarks (Pillow, `muriel.typeset`) |
| [SVG](plugins/muriel/skills/compose/channels/svg.md) | Paper figures, data-driven vectors, icons, wave fields (plain SVG, optionally `svgwrite` and `cairosvg`) |
| [Diagrams](plugins/muriel/skills/compose/channels/diagrams.md) | Named forms such as 2×2, cycle, pyramid, swimlane, Sankey, treemap, and DAG, each with a stated test for when it fits (muriel's generators; Mermaid and MathJax through Node) |
| [Charts](plugins/muriel/skills/compose/channels/charts.md) | Quantitative charts in JS libraries (Recharts, ECharts, Chart.js, Plotly, D3) |
| [Science](plugins/muriel/skills/compose/channels/science.md) | Paper figures, notebook editorial, APA-style stats (matplotlib, LaTeX, `muriel.stats`) |
| [Infographics](plugins/muriel/skills/compose/channels/infographics.md) | Single-image explainers (generated SVG) |
| [Web](plugins/muriel/skills/compose/channels/web.md) | Blog posts, magazine layouts, HTML to PNG or PDF (marginalia, pandoc, Playwright or WeasyPrint) |
| [Interactive](plugins/muriel/skills/compose/channels/interactive.md) | Live demos with parameter controls (WebGL, Canvas, D3, PixiJS) |
| [Polish](plugins/muriel/skills/compose/channels/polish.md) | UI detail: radii, press states, hit areas, icon motion (CSS, TSX, HTML) |
| [Spatial](plugins/muriel/skills/compose/channels/spatial.md) | Perspective grids, layered typography, ridge plots (`muriel.spatial`, Three.js) |
| [Video](plugins/muriel/skills/compose/channels/video.md) | Product demos, GIFs, HTML to MP4 (ffmpeg, hyperframes) |
| [Terminal](plugins/muriel/skills/compose/channels/terminal.md) | Sparklines, bar charts, tables in Unicode (`muriel.chart`) |
| [Heatmaps](plugins/muriel/skills/compose/channels/heatmaps.md) | Fixation density overlays (`muriel.typeset`) |
| [Gaze](plugins/muriel/skills/compose/channels/gaze.md) | Scanpaths, AOI timelines, saccade roses (Pillow) |
| [README](plugins/muriel/skills/compose/channels/readme.md) | Repo front pages rendered by GitHub (`muriel.capture`, `muriel.squint`, `muriel.aiism`) |
| [Prose](plugins/muriel/skills/compose/channels/prose.md) | Plain text people read: store listings, release notes, UI strings, explainers, reports (reader contract, registers, `muriel.aiism`) |

Two references apply to every channel. [Dimensions](plugins/muriel/skills/compose/channels/dimensions.md) covers social cards, device sizes, paper, and video resolutions. [Style guides](plugins/muriel/skills/compose/channels/style-guides.md) defines the `brand.toml` schema, which imports from Google Stitch `design.md` (`muriel import`) and exports W3C design tokens (`muriel export-dtcg`).

The web and kinetic-type docs default to two sibling projects, [marginalia](https://github.com/andyed/marginalia) and [iblipper](https://github.com/andyed/iblipper2025), because they pass muriel's rules without changes. Substitute your own libraries freely. Each channel names the library it assumes, and none of the rules depend on it.

Collections of many images default to a third sibling, [Wunderkammer](https://github.com/andyed/wunderkammer), whose 3D views draw with muriel's renderer; [`references/collections.md`](plugins/muriel/skills/compose/references/collections.md) covers when to use it and how.

## Design languages

A channel is a medium; a vocabulary is a style the agent can work in. Ten ship under [`vocabularies/`](plugins/muriel/skills/compose/vocabularies/):

- [Visible Language Workshop](plugins/muriel/skills/compose/vocabularies/visible-language.md): dynamic typography, information landscapes, type as data
- [FUI](plugins/muriel/skills/compose/vocabularies/fui.md): the HUDs and consoles of film and game interfaces
- [Kinetic typography](plugins/muriel/skills/compose/vocabularies/kinetic-typography.md): letters that move with intent
- [Declassified](plugins/muriel/skills/compose/vocabularies/declassified.md): the look of released and redacted documents, from black bars to scan damage
- [Surfaces](plugins/muriel/skills/compose/vocabularies/surfaces.md): composed archetypes such as decks, dashboards, posters, and social cards
- [Data-viz platforms](plugins/muriel/skills/compose/vocabularies/data-viz-platforms.md): the charting guides of Apple, Material, Carbon, Observable, and newsrooms
- [ECharts](plugins/muriel/skills/compose/vocabularies/echarts.md), [PixiJS](plugins/muriel/skills/compose/vocabularies/pixijs.md), and [KaTeX](plugins/muriel/skills/compose/vocabularies/katex.md): the idioms of each library
- [muriel's own brand](plugins/muriel/skills/compose/vocabularies/muriel-brand.md), written up the same way

## Rules every channel enforces

From [`SKILL.md`](plugins/muriel/skills/compose/SKILL.md):

- Text contrast of at least 8:1 against its background. No opacity on text; pick an explicit color.
- Body copy and captions at 16 px or larger, body weight 500 or heavier.
- Measure text width, plot bounds, and target dimensions before drawing.
- Label every important number, unit, axis, state, and control.
- One dominant focal point per composition.
- Pointer targets of at least 40 × 40 px.
- Reproducible output: fixed seeds, recorded dimensions, local assets.
- Use the project's brand. Without one, use near-black, cream, and cyan.

Most of the rules predate the tooling. They come from Cooper's Visible Language Workshop, Tufte's data-ink ratio, Bertin's retinal variables, Gestalt grouping, and eye-movement research.

## Interaction design

muriel designs how an interface behaves as well as how it looks. It draws on cognitive psychology, perception research, and HCI to choose a mechanism, then builds the mechanism and exercises it in the host product. Rendering and interaction checks are evidence about the artifact. Explicit models support conditional predictions; measured benefits in comprehension, workload, or learning need evidence from people.

[`human-capabilities.md`](plugins/muriel/skills/compose/references/human-capabilities.md) covers task framing, the split of work between people and AI, and the limits of evidence. [`task-analysis.md`](plugins/muriel/skills/compose/references/task-analysis.md) turns a goal into alternative methods, selection rules, knowledge requirements, a first-use walkthrough, and acceptance journeys before controls are arranged. [GOMS](plugins/muriel/skills/compose/references/goms.md) covers timing and procedure models. [Task observation](plugins/muriel/skills/compose/references/task-observation.md) turns interaction events into evidence, drawing on Hilbert and Redmiles, Edmonds's Uzilla, and *Instrumenting the Dynamic Web*.

[`microstrategies.md`](plugins/muriel/skills/compose/references/microstrategies.md) is built on Gray's *Milliseconds Matter*: small differences in the cost of reaching information change the routines people adopt. Convention is a starting hypothesis. muriel can propose a new interaction, build a working probe, and weigh what it makes possible against what it costs to learn.

Zooming interfaces, semantic zoom, linked displays, brushing, and faceted exploration share one contract, in [`multiscale-coordination.md`](plugins/muriel/skills/compose/references/multiscale-coordination.md): entities keep a stable identity when their representation changes, queries and selections have explicit meanings, and gestures are recoverable. Camera navigation is covered in [`zooming-interfaces.md`](plugins/muriel/skills/compose/references/zooming-interfaces.md) and attribute filters in [`faceted-exploration.md`](plugins/muriel/skills/compose/references/faceted-exploration.md). Adapters for D3, Vega-Lite, ECharts, and Canvas are in [`multiscale-adapters.md`](plugins/muriel/skills/compose/references/multiscale-adapters.md), and briefs and fixtures for testing the contract in other domains are in [`multiscale-evaluation.md`](plugins/muriel/skills/compose/references/multiscale-evaluation.md). The [Linked Atlas lab](https://muriel.mindbendingpixels.com/examples/linked-atlas/) ([source](plugins/muriel/skills/compose/examples/linked-atlas/)) is a working example with synthetic data and no dependencies.

The literature reviews behind these references are in [`research/`](research/).

## Checking its own work

muriel renders what it makes and measures the result:

- `muriel diagram-check` fails a figure whose labels collide, run off the canvas, or spill out of their shapes, or whose text falls below 8:1 contrast.
- `muriel.layout.place_label` puts an annotation where it collides with nothing, falling back to the margin. It never shrinks text or hides data behind a halo.
- `muriel capture` screenshots a page across viewport sizes.
- `muriel squint` blurs the capture to show whether the hierarchy survives.
- `muriel loupe` cuts 4× close-ups of the busiest regions to show whether line ends and joints hold up.

[`muriel-critique`](plugins/muriel/agents/muriel-critique.md) is a read-only subagent. Given a rendered artifact, it lists each way the artifact breaks muriel's rules, the channel's anti-patterns, or an optional `brand.toml`, with evidence. It is hardened against instructions and fake contrast claims embedded in the image. Ask for it by name:

> Run muriel-critique on `path/to/artifact.png` with channel `raster` and brand `examples/muriel-brand.toml`.

The verdict is `PASS`, `NEEDS REVISION`, or `FAIL`, followed by numbered issues with rule, evidence, fix, and severity. Any CRITICAL issue fails the artifact; any HIGH issue sends it back for revision. Adversarial and baseline test cases live in [`examples/critique-fixtures/`](plugins/muriel/skills/compose/examples/critique-fixtures/), and new attacks are welcome as pull requests.

A jury splits that review across seven narrower seats, used to find defects or to choose between design directions. Each seat sees the artifact through one restricted view, defined in [`references/jury.md`](plugins/muriel/skills/compose/references/jury.md):

| Seat | Judges | Denied |
|---|---|---|
| `muriel-squinter` | Hierarchy and reading order under heavy blur | The sharp render, all text, the brief |
| `muriel-thumbnail` | Whether the main signal survives at 1/8 scale and 16 px | The full-size render and the blur ladder |
| `muriel-loupe` | Whether line ends, joints, and edges hold up in 4× close-ups | The whole composition, the brief |
| `muriel-stranger` | What the artifact is for, from a single read | The brief, other ballots, project context |
| `muriel-forger` | Whether a generic template can rebuild it, by trying | The brand tokens |
| `muriel-pedant` | Labels, units, and numeric claims | The rendered composition |
| `muriel-walker` | Whether a multi-step flow holds together, walked frame by frame with the task | The design rationale, the implementer's claims |

Run each seat as its own subagent. The restrictions hold only because the seat never receives the withheld material in its context.

## More ways to install

### Other agent harnesses

`SKILL.md` uses the [Agent Skills](https://github.com/anthropics/claude-code/blob/main/docs/skills.md) format. The repo includes `.agents/skills/muriel`, a symlink to the skill, which Codex CLI reads natively and Cursor, Gemini CLI, GitHub Copilot, OpenCode, and Pi read as an alternate path. Not every harness has been verified yet; [`HARNESSES.md`](HARNESSES.md) tracks the checklist. Kiro, Qoder, Rovo Dev, and Trae need manifest shims that have not landed.

### Python package and CLI

muriel is not on PyPI yet. Install the wheel from the latest release:

```bash
pip install https://github.com/andyed/muriel/releases/download/v0.15.0/muriel-0.15.0-py3-none-any.whl
```

The core package has no dependencies. Extras add one backend each: `raster` (Pillow, NumPy), `critique` (cairosvg), `faces` (MediaPipe), `text` (EasyOCR), `saliency` (ONNX Runtime), or `all`. `muriel doctor` reports what is installed.

```python
from muriel import matplotlibrc_dark            # applies a dark matplotlibrc on import
from muriel.stats import format_comparison      # APA-style reporting
from muriel.contrast import audit_svg           # 8:1 contrast audit
from muriel.styleguide import load_styleguide   # brand.toml loader
from muriel.dimensions import figsize_for, OG_CARD
```

```bash
muriel                               # list subcommands
muriel contrast page.svg             # 8:1 audit of an SVG or HTML file
muriel diagram-check figure.svg      # accessibility lint, label geometry, contrast
muriel capture https://example.com   # screenshots across viewport sizes
muriel squint capture.png            # blur ladder: does the hierarchy survive?
muriel loupe figure.svg              # 4× close-ups: do the joints hold up?
muriel styleguide brand.toml --css   # CSS custom properties from a brand.toml
muriel heroshot in.png out.png --tilt 12 --brand brand.toml --target og.card
```

Each subcommand also runs as a module, for example `python -m muriel.capture`.

### From a checkout

To work on muriel itself, install from a clone so edits take effect immediately:

```bash
git clone https://github.com/andyed/muriel ~/Documents/dev/muriel
cd ~/Documents/dev/muriel && ./install.sh
```

`install.sh` links `plugins/muriel/skills/compose/` to `~/.claude/skills/muriel` and `plugins/muriel/agents/` to `~/.claude/agents/muriel`. New channels and jury seats appear without a re-run, and the bare `/muriel` command works. The script refuses to run if the plugin is already installed, to avoid loading muriel twice. If it finds an older mount, it reports it and stops; `./install.sh --repair` moves the old mount to `muriel.bak-<timestamp>` and links the new one.

### Repository layout

- [`plugins/muriel/skills/compose/`](plugins/muriel/skills/compose/): the skill (`SKILL.md`, channels, references, vocabularies, examples)
- [`plugins/muriel/agents/`](plugins/muriel/agents/): the critique agent and the seven jury seats
- [`muriel/`](muriel/): Python package and CLI
- [`render_assets/`](render_assets/): Three.js and CSS3D exemplars for the spatial channel
- [`research/`](research/): literature reviews and bibliographies behind the references
- `.claude-plugin/marketplace.json`: the marketplace entry. The plugin manifest is `plugins/muriel/.claude-plugin/plugin.json`.

- [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design): layout geometry for `layer_stack`, `pyramid`, and `swimlane`, adapted under MIT.
- [caylent/tufte-data-viz](https://github.com/caylent/tufte-data-viz): the rule structure and anti-pattern format of the charts channel.
- [thedavidmurray/claude-make-interfaces-feel-better](https://github.com/thedavidmurray/claude-make-interfaces-feel-better): the 16 rules in the polish channel.
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable): the absolute bans and reflex-font list in the web channel.
- Steve at Druck I.T., [“I Turned My Git History Into a UX Skill”](https://druckit.wordpress.com/2026/08/19/i-turned-my-git-history-into-a-ux-skill/): the host-native review pass.
